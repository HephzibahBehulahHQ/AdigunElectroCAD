# CAD interaction

## Existing commands and document effects

| Surface | Command and effect |
| --- | --- |
| File | Restore or import replaces the project through the edit history. Local and cloud save/load use project JSON. JSON, SVG and PNG export and Print read the current project or drawing. |
| Edit and toolbar Undo/Redo | Restore a previous or subsequent project snapshot. |
| View and toolbar Zoom, Fit, Grid | Change canvas scale, framing or grid visibility. Entity coordinates stay in sheet units. |
| Insert menu and toolbar Insert | Place the selected catalog definition as a real component instance with collision checks and stable terminal IDs. |
| Electrical and toolbar Wiring | Validate topology, create or extend a continuation, or connect selected compatible terminals. |
| Draw toolbar | Place text and geometric primitives in the sheet document. |
| Simulation menu and toolbar | Run, Pause and Stop the runtime. Design and runtime state have separate lifecycles. |
| Reports, Help, Projects and Laboratory | Generate reports from the current document, open documentation, load an editable template, or open the independent lab. |
| Canvas, sheet tabs, and Properties | Select entities, move components and terminal routes, edit sheet and entity data, and invoke the existing geometry and stacking commands. |

On free sheets, select one or more components and use **Drafting order** in Properties. These commands save a `zIndex` per component and preserve the selected group’s relative order. Symbols and wire hit targets render in that order. Old projects without a stacking index keep their component array order, and new unranked components render above ranked components. A stack edit is one Undo step and leaves terminal IDs, wire links, collision rules, and simulation traversal order intact. This operates within the existing component layer.

Select a component or wire and use **Layer and stroke** in Properties to create and assign a named sheet layer. Its color, lineweight and line type apply to all members. The entity fields override the layer's lineweight and line type, and the existing drafting color controls override its color. Leave an entity field blank or choose **Inherit** to use the layer value. Lineweight is measured in drawing units and accepts 0.5–12. Creating, assigning, and styling layers are undoable. Layer settings are saved in project JSON and render in standalone SVG without changing electrical connections or simulation. On a free sheet, toggle a named layer under **View → Layer visibility**. Hidden symbols and terminals are omitted from the drawing, while wires on visible layers retain their terminal coordinates. Visibility and lock settings are saved and undoable. Use **View → Layer lock** to prevent changes to the components and wires assigned to a named layer. Visible locked entities remain on the drawing. A locked wire continues to follow its terminals when an unlocked component moves. Move a named layer forward or back under **Layer and stroke** to control the relative stacking of assigned symbols and of assigned wires. Unassigned entities keep their own order above named layers. Wire geometry stays behind symbols, and terminal hit targets follow symbol order.

Pick a part in the component bank and click clear space on a free sheet, or drag the part directly from the bank. Escape cancels placement. Free-sheet components can be selected individually, added with Shift+Click, or selected by dragging a box across empty canvas. Dragging moves the whole selected group without grid snapping. Properties also accepts precise X and Y coordinates, and its arrow controls nudge the group. Connected wires and dependent branch taps follow during preview. A drop is rejected atomically if a symbol or label overlaps a stationary component or leaves the sheet. Accepted placement and movement preserve terminal endpoints and are undoable. The pick, place and connect sequence follows the interaction of [AdigunSimulator](https://github.com/HephzibahBehulahHQ/AdigunSimulator/blob/main/app.js).

On free sheets, component positions may be negative or extend past the old export frame. Drag, duplicate, arrow movement, rotation and numeric placement use the same neighbor-clearance rules. Quick Insert searches the current view and switches to click placement if it finds no clear position. The fixed reference sheet retains its frame limits.

While placing a catalog component, its preview uses the same symbol, terminal positions, and guide-snapped reference point as the committed instance. A red dashed outline shows that the shared clearance rules reject the position. The preview is omitted from drawing exports.

Select one component on a free sheet to show its resize and rotation handles. Drag the lower-right handle to scale the symbol uniformly around its center in 5% steps, from 50% to 200%. Drag the upper handle to snap rotation to a right angle, or click it to turn 90° clockwise. With either handle focused, arrow keys step the transform. Properties offers the existing size field and Rotate 90° button, plus an exact rotation selector. During an accepted preview, terminal markers, labels, and connected routes follow the transformed symbol. Releasing the pointer commits one undoable edit if the proposed transform clears the sheet edges and neighboring symbols.

Dragging is disabled in Wiring mode and for the fixed DOL reference sheet. The free-sheet preview follows the pointer and recomputes wire endpoints from the preview position. Design edits reset runtime simulation state.

On a free sheet, the SVG view fills the canvas viewport. Wheel zooms around the pointer. Pan with middle-drag, Space + drag, or Shift + wheel for horizontal movement. Toolbar zoom keeps the view center fixed. Fit frames the drawing, while View → Fit Selection frames the selected objects and Go to Origin centers zero. Resizing the viewport leaves the model coordinates unchanged. The reference DOL view retains its existing scroll navigation. Export SVG and Export PNG use the complete free-sheet drawing extent, independent of the camera. Export frame SVG uses the legacy 1100 × 780 frame and warns before clipping. The PNG raster uses at most 4096 pixels on its longest edge.

Drag from the top ruler to create a horizontal guide or from the left ruler to create a vertical guide. Use View → Drawing guides to enter exact signed coordinates, move a guide numerically, lock, hide, or remove it. Guide changes are undoable and saved with the current sheet. Component placement and new text can snap within eight screen pixels of a visible guide, with the cursor display reporting the resolved point during click placement. Hidden guides do not snap. Guides do not create electrical connections or appear in drawing exports.

View → Grid settings stores separate display and snap intervals on each free sheet. The screen may omit fine grid lines when zoomed out, while routed waypoints, text, and shape drafting keep their configured snap interval. Turn off grid snapping to enter those points without rounding to a grid. The existing Grid toggle controls visibility independently. Component placement continues to follow the pointer or a nearby visible guide, and wiring uses exact terminal positions.

Open View → Print layout to configure a free sheet's paper frame. Choose A4 through A0 or a custom format, set orientation, a uniform margin, the frame origin, and how many drawing units map to one printed millimeter. Fit Print Frame moves only the camera. Export frame SVG uses the saved paper dimensions in millimeters and includes the frame and optional title block even if the overlay is hidden. Complete-drawing exports use content bounds and omit the paper overlay. Older sheets without a configured layout retain the legacy frame export.

File → Print schematic opens the frame in the browser's print dialog. To produce a framed PDF, select Save as PDF at actual size with browser headers and footers disabled. The print document sets the saved physical paper size and includes the frame, title block, and schematic without editor controls.

Open Engineering reports and select Active sheet or Entire project before using the browser’s Print command. The selected report scope follows the schematic on separate pages. Report tables expand to include every row and repeat their column headings on subsequent pages. The browser printout hides the workspace dock, header utilities, rulers, and drawing handles.

Click a terminal in Select or Wiring mode to start a wire. Wiring mode gives isolated pins a larger click target and shows the current instruction or connection error on the free-sheet canvas. Click a compatible terminal to finish with an automatic orthogonal route. Free sheets try nearby clear corridors if the center route crosses an unrelated symbol. When no supported corridor is clear, use custom bends to route around the obstruction. To specify the route, click empty drawing space to add one or more bends before clicking the destination terminal. The dashed preview follows the pointer, and bends use the sheet's snap setting. Escape cancels the unfinished wire. A finished wire retains its terminal identities when either component moves, and custom bends stay at their drawing coordinates.

On 2026-11-22, headless Chrome ran the editor at commit `aedc4d0` with a local three-component project. Browser-dispatched clicks created an automatic wire and a wire with two bends. The Properties move command relocated the shared source, then the second destination. Both rendered routes matched the new terminal coordinates and survived a local save and reload. Physical pointer dragging and live screen-reader behavior still need workstation verification.

Space activates a focused wire, terminal, or continuation control. With focus on the drawing itself, hold Space and drag to pan.

Shift-clicking a target keeps the source active so users can add more terminal branches. To branch from a wire on a free sheet, click near its visible route and then choose a compatible terminal. Shift-click targets to add more branches at that attachment. The saved branch records its parent wire, source endpoint, and relative route position, so moving the parent endpoints moves the displayed tap. The electrical model connects the new wire to the selected parent endpoint. Removing the parent wire also removes its dependent branches.

Switching sheets discards an unfinished local wire, branch, or reconnection. To connect different sheets, start **Electrical → Add sheet continuation** and choose the source terminal before switching sheets. Focus an existing continuation marker and press Space to edit its properties on the current sheet, or press Enter to follow it to the linked sheet.

Select a wire to change its conductor color or replace either terminal in Properties. Reconnection validates the revised topology and carries dependent branch taps with their parent endpoint. Replacing a branch’s source detaches it from the old parent. For any direct wire on a free sheet, including example wires, use Edit route points and Add route point. Click the selected route to insert a waypoint, then drag it or use the arrow keys. Right-click a handle or press Delete to remove the point. Reset to automatic route clears waypoints. To reposition a branch tap, edit its parent route.

Validation names unrelated symbols crossed by a saved manual route. The active-sheet check in the project library also fails when a saved route is obstructed, even when its electrical sequence passes.

When a waypoint moves, the preview recalculates attached taps and their branches from the preview route. Releasing the waypoint saves the route in one undoable edit.

For selected line, rectangle, or ellipse drafting geometry, edit X1, Y1, X2, and Y2 numerically in Properties for exact placement and sizing. Coordinates stay within the 1100 × 780 sheet and the shape must span at least 4 units. Polyline and polygon geometry remains editable by its vertex handles.
Use Freehand to sketch an unfilled path by dragging on a free sheet. The path is stored as editable polyline geometry, so users can rename it, choose its color and stroke width, and move or edit individual vertices later. Freehand drawings are visual drafting marks and do not create electrical connections.
On a selected graphic, choose Make component symbol to turn that one drafted shape into a generic, named user symbol. The shape is centered and fitted inside its symbol body; the original is removed only when placement succeeds. Properties lets users change its name, color, terminal labels, kinds, directions, and added terminal anchor positions. Duplicate the component to reuse the authored shape. The symbol is a drawing and connectable terminal set only; it does not imply a voltage or simulated behavior.
Shift-click additional drafted graphics to select a composition, then choose Make symbol from N graphics in Properties. The shapes are centered and fitted together while preserving each shape’s color, fill, and stroke; the active graphic stays individually editable until conversion.
An interface relay with a control supply reaching A1 or A2 derives its state from the wired coil circuit and configured voltage rating. Its changeover poles switch independently. A relay driven only by Boolean signals continues to use its signal input.

On a custom pilot indicator, set the rated voltage and AC/DC mode in Properties, then wire its control terminals T1 and T2. For DC, connect positive to T1 and return to T2. The lamp lights only with a complete matching supply path. A rating of zero leaves an older indicator unrated until configured. Alternate terminal labels keep the original physical identities. Extra terminals remain available for drafting and wiring and do not drive the lamp. The model uses ideal continuity and voltage matching, with no modeled current draw or inrush.
For added terminals on the generic user symbol, edit the local X/Y anchor offsets in Properties. Offsets are bounded to -60..60 units, follow component scale and rotation, and move the wire connection point and terminal label together. Built-in T1/T2 pin endpoints stay aligned with the indicator glyph.
