# Wired pneumatic command and motion models

The placed 5/2 and 3/2 valve commands now read their connected Boolean inputs. Their CMD output carries a typed `motion` signal: extend, retract or hold. A cylinder's CMD input consumes it, and POS % publishes its current position as a numeric scalar. These are command/motion connections, not physical air hoses or pressure ports.

The 5/2 component explicitly models a double-solenoid bistable valve. EXT/RET select its position; releasing both coils retains the last scanned position. `initialPosition` configures its deterministic starting state as extend or retract. It is not a claim that physical bistable valves have a defined de-energized normal position; see [Festo's description](https://ftp.festo.com/public/pneumatic/SOFTWARE_SERVICE/Documentation/2021/US/DNCV_ENUS.PDF). Both coils active produce an error: switching dominance is not modeled. The simulator inhibits downstream motion in that condition; this is not a certified physical safe-stop function.

The spring-return 3/2 component maps an energized EN input to extension and a dropped EN input to retraction. The single-acting example demonstrates the resulting spring-return motion. Its control abstraction assumes the required air/spring conditions; it does not calculate pressure or return force.

Cylinder position advances on each positive runtime-clock step at a constant rate: 100% stroke per `travelSeconds`. Position clamps at 0/100%. Pause preserves it. Stop clears runtime position/spool state and restores the configured design. Full travel must be finite and at least 0.001 seconds; starting position is 0–100%. `elapsedSeconds` is an initial-motion preset retained for older snapshots, not a repeated per-render time advance. New components default that preset to zero.

Existing EN or EXT/RET input IDs remain available as direct Boolean motion commands. Wired commands override manual `direction`. Single-acting EN false retracts; double-acting EXT/RET both false holds. Use either direct inputs or the valve CMD path. Mixing them reports an ambiguous-command error. Model evaluation does not mutate saved design properties.

Incompatible incoming units now report a signal fault rather than silently using configured fallback values. This also applies to ADC inputs and mixed-unit math. Fault-tagged values propagate through modeled inputs and clear Boolean commands. Correction clears the derived fault on the next evaluation. Direct motion-to-Boolean wires are rejected; an incompatible command routed through COM is still caught at runtime.

The library adds two distinct projects: **5/2 bistable valve and double-acting cylinder** and **3/2 valve and spring-return cylinder**, under Pneumatic Control. Each includes real command wires, cylinder position feedback, a numeric threshold and an output coil, plus its own checked operating sequence. The library now contains 502 entries: the existing 499 parameter variants, one dedicated analog project and these two pneumatic projects. It does not establish 502 independently engineered industrial projects.

Logical-control and pneumatic anchors now put command inputs left, outputs right and COM below the body. IDs/topology are preserved, and anchors rotate with the symbol. The checked examples no longer route wires through valve/comparator bodies. This can change the displayed routing of existing logic circuits; exhaustive rendered coverage of every saved project remains unverified.

Validation: 299 local workspace tests and production build passed, including wired bistable/spring-return operation, feedback thresholds, end stops, conflict/invalid-input inhibition, direct-input compatibility, unit rejection, Pause/Stop, import round trips, distinct/rotated anchors and both recorded project sequences. The workspace also includes separate draft work.

Browser checks loaded both real library entries. The double-acting example paused at 42.5%, remained there during Pause, resumed to 65% after releasing its coil, reversed to 30%, and reset to 0% on Stop. The single-acting example extended to 40% and returned to 0% after dropping its coil. At full extension, position feedback energized HL1. Rendered checks at 1672×941 after Fit showed separate references and wire paths outside symbol bodies. Undo/reload restored the original two-sheet preview; the temporary viewport was reset.

Air availability, compressibility, pressure/flow networks, loading, friction, cushioning, leakage, mechanical collision, valve switching delays and manufacturer-specific dominance are not solved. The separate Industrial Device Lab remains a property-based demonstration. These motion models do not complete physical pneumatic/hydraulic simulation or safety validation. Mobile and production behavior remain unverified.
