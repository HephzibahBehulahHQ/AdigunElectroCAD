# Nine-motor feeder workbook

This educational example has ten editable sheets: one three-phase source and nine direct-on-line motor feeder circuits. Each feeder includes its own three-pole breaker, contactor, thermal overload relay, three-phase motor, control supply, stop/start pushbuttons. Local devices are connected with actual catalog terminal IDs and local wires.

L1, L2, L3, and PE have project-level continuation records from the source sheet to the real breaker or motor terminals on each feeder sheet. A continuation label shows its source sheet/grid and the destination sheet/grid and can navigate between the pages.

The catalog's example values include a 400 V, 50 Hz source, nominal 7.5 kW motors, and catalog-default protection values. This workbook does not select equipment for a real installation: source capacity, conductor sizing, fault levels, and protection coordination are unspecified. The free-sheet branches do not claim runtime simulation.
