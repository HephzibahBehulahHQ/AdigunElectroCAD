# Type K thermocouple model

The placed thermocouple now uses the [NIST ITS-90 Type K forward reference function and tables](https://its90.nist.gov/downloadFiles/type_k.tab.txt), replacing the constant 0.041 mV/°C approximation. The [NIST database description](https://www.nist.gov/publications/nist-60-nist-its-90-thermocouple-database) identifies its relationship to Monograph 175.

The implementation evaluates the negative-temperature polynomial and positive-temperature polynomial plus exponential term using the published coefficients. Both junction temperatures must be finite numbers within −270 to 1372 °C. `temperatureC` is the measuring junction; `referenceJunctionC` defaults to 0 °C for existing projects. Terminal EMF is E(measuring junction) − E(reference junction), in mV. Equal junction temperatures give zero; reversing them reverses polarity. This models terminal voltage relative to the specified reference junction, not an inverse voltage-to-temperature instrument or an automatically compensated temperature display.

The catalog identifies the component as Type K. Its SIG terminal supplies the same mV value shown by its result panel. Numeric logic blocks can read that signal. Invalid junction temperatures produce a visible error and a fault-tagged signal; the fault propagates through modeled input bindings and suppresses downstream output signals instead of using configured fallback values. A new evaluation after correcting the temperature clears the derived fault. The saved component properties are not mutated by evaluation.

Independent rounded NIST table checks cover −270, −200, −100, 0, 100, 500, 1000 and 1372 °C with a 0.00051 mV allowance for table rounding. Additional tests cover reference-junction differences, polarity, equal junctions, malformed/range-invalid inputs, and a wired sensor → comparator → coil chain including invalid-input suppression and recovery. At 500 °C with a 0 °C reference, the table value is 20.644 mV; a 20.6 mV threshold distinguishes it from the former linear approximation's 20.5 mV.

The wired fault regression also commands a forward contactor from the sensor/comparator chain: a valid reading permits the modeled motor to run; an invalid reading clears the evaluated contactor command and leaves the motor in STANDBY even when its configured command was true. This checks the simulator's error path, not a certified physical protection system.

Local browser verification placed the Type K component and checked 20.644 mV at 500 °C/0 °C, then 16.548 mV at 500 °C/100 °C. Entering 2000 °C displayed the supported-range error without crashing the app. Undo removed all test edits and reload confirmed the original two-sheet preview. The local workspace's 271 tests and production build passed; it also includes separate drafts #62–#64. The official text reference was retrieved on 2026-11-03 (SHA-256: 68c0a67147aa0b360b4349d4bb88bca2d6d83335caac15a6e124b1b955a40f03); the downloaded source stays outside the repository.

This is a reference transfer function, not a manufacturer calibration, tolerance-class certification, sensor dynamics model, physical supply/return solver or protection function. Other thermocouple types, lead-wire errors, electrical noise, thermal lag and inverse temperature conversion remain unmodeled. Production behavior remains unverified.
