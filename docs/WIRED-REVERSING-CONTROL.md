# Wired forward/reverse interlocks

The dedicated project uses two contactors with actual A1/A2 coil paths, NO 13–14 holding contacts and NC 21–22 auxiliary contacts. Each opposing NC contact is in series with the other coil. KM2 exchanges two power phases; the nominal motor output therefore changes from +1440 to -1440 rpm. This is an ideal steady-state electrical model, not a mechanical reversal or coast-down model.

Load **Wired forward/reverse interlocks**. Use S1 **Live Pressed** for forward, then release it. Pressing S2 while KM1 holds must leave KM2 off. Release S2, press/release S0 STOP, then press/release S2: KM2 holds reverse. S1 cannot energize KM1 while reverse holds. Release commands before tripping/resetting F1; reset alone must not restart the motor.

Starting from rest with both commands asserted produces a non-settling contact network. The solver inhibits both coils and reports the conflict; it does not choose an arbitrary direction. Removing the conflict permits the remaining command to operate. Broken NC series paths or A2 returns prevent their respective coil from energizing. Power and control supplies are independent: main-power restoration while a coil remains held can restart the nominal motor. Held START during STOP/overload recovery can also restart this conventional circuit.

No mechanical interlock, contact timing/bounce, physical pickup curve, torque, coast-down, thermal trip curve or safety certification is modeled. These limitations remain part of the wider release gates. Automated tests verify the operating sequence, component/wire-order independence, conflicting commands, broken interlock/return wires and sheet bounds. Local browser acceptance passed: forward +1440 rpm with KM2 off despite reverse command; STOP left STANDBY; reverse -1440 rpm with KM1 off despite forward command; overload trip/reset left STANDBY. The original two-sheet local project was restored. Routes and sheet bounds were reviewed and regression-tested; all 859 tests and the production build passed. Production acceptance remains pending.
